01
HARDWARE

Wire the sensors

Connect DHT11 data to GPIO 4 and MQ-2 analog output to GPIO 34. Use a divider if the MQ-2 output can exceed 3.3 V.

DHT11 · GPIO 4MQ-2 · GPIO 34
02
LOCAL ALARM

Add the indicators

Use GPIO 18 for the red LED, GPIO 19 for the green LED, and GPIO 26 for a buzzer driver. Add LED resistors and drive the buzzer through a transistor.

RED · 18GREEN · 19BUZZER · 26
03
ARDUINO IDE

Upload the firmware

Install the ESP32 board package, Adafruit DHT sensor library, and Adafruit Unified Sensor library. Open the sketch with its adjacent Config.h.

ESP32 DEV MODULE9600 BAUD
04
DASHBOARD

Connect the backend

Run Docker Compose, set the Wi-Fi network and API settings in Config.h, then upload again. Local LED and buzzer alerts operate on the ESP32.
