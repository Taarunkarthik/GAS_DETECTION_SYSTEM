GETTING STARTED

Bring your fire monitor online.

This project uses an ESP32 DevKit V1, an MQ-2 gas/smoke sensor, a DHT11 temperature/humidity sensor, and a small Node.js backend. The dashboard and the board must be able to reach the same backend.

Prototype only: MQ-2 readings are raw, uncalibrated sensor values. This project is not a certified fire alarm and must not replace approved smoke alarms, fire systems, or emergency procedures.

How the pieces connect

ESP32 + sensorsSamples every 2 seconds
→ HTTP POST
Node.js backendValidates and thresholds data
→ SSE stream
Web dashboardLive values, chart and alert popup

The ESP32 sends JSON to /api/readings with the X-Device-Key header. The backend stores each sample, detects alarm transitions, and streams updates to open browsers. LED and buzzer outputs run locally on the ESP32, so they do not depend on the website.

Wire the ESP32

PARTCONNECTIMPORTANT
MQ-2 moduleVCC → 5V, GND → GND, AO → divider → GPIO 34Use two 10 kΩ resistors: AO → 10 kΩ → GPIO 34; GPIO 34 → 10 kΩ → GND. This halves a 5 V AO signal. Share ground.
DHT11VCC → 3.3V, GND → GND, DATA → GPIO 4A bare sensor needs a pull-up from DATA to 3.3V. Many breakout modules already include one.
Red alert LEDGPIO 18 → 220–330 Ω resistor → LED anode; cathode → GNDUse an external LED.
Green safe LEDGPIO 19 → 220–330 Ω resistor → LED anode; cathode → GNDUse an external LED.
Active buzzerGPIO 26 → 1 kΩ → NPN transistor base; emitter → GND; collector → buzzer negative; buzzer positive → its rated supplyDo not power a buzzer directly from a GPIO. Join external supply ground to ESP32 ground. Add a flyback diode for a magnetic buzzer.

GPIO 34 is an ADC1 input on the classic ESP32 DevKit V1. Use the pin map for your specific board if you have another ESP32 variant. The ESP32 ADC accepts a limited input range; never connect the MQ-2's 5 V analog output directly.

Start the website and backend

  1. Install and start Docker Desktop, then open PowerShell in the project folder.
  2. Copy .env.example to .env if needed.
  3. Run docker compose up --build -d to build and start the backend container.
  4. Open http://localhost:3001. View logs with docker compose logs -f; stop it with docker compose down.
  5. For ESP32 local testing, find the computer's private IPv4 address with ipconfig. On Windows, allow Docker Desktop through the private network firewall if prompted.

Upload the Arduino sketch

  1. In Arduino IDE, install the ESP32 board package from Espressif and select your ESP32 Dev Module (or the matching board).
  2. Install the DHT sensor library by Adafruit and Adafruit Unified Sensor.
  3. Open firmware/esp32_fire_alert/esp32_fire_alert.ino. In the adjacent Config.h, set your 2.4 GHz Wi-Fi SSID/password, your computer's IP in API_URL, and the device key.
  4. Keep the computer and ESP32 on the same Wi-Fi network, upload, and open Serial Monitor at 9600 baud.
  5. When the Serial Monitor says a dashboard update was sent, refresh the dashboard. It updates live after that.

Example local Docker endpoint: http://192.168.1.25:3001/api/readings. Replace the IP with your computer's LAN address. Docker Compose maps host port 3001 to container port 3000. Do not use localhost in the ESP32 URL: from the board, that would mean the board itself.

Thresholds and calibration

The starter thresholds are 30°C warning / 35°C fire and MQ-2 ADC 400 warning / 500 fire on a 0–4,095 scale. These demo values are not validated fire thresholds. The system shows safe, warning, and fire states. Update both Config.h and the matching values in .env if you tune them. Either sensor can raise the state.

MQ-2 modules need warm-up and individual calibration; follow the documentation supplied with your module (initial burn-in can be many hours). The ADC number is not ppm and is not a reliable measure of smoke density without calibration. Never test with an open flame.

Using it away from your Wi-Fi

A Docker container on your own computer is not publicly reachable. The Vercel site needs the container on a public server with HTTPS. Set WEB_ORIGINS to the exact Vercel origin, set window.EMBERWATCH_API_BASE in public/config.js to the backend origin, and set the ESP32 API_URL to the backend's /api/readings endpoint. Add the trusted root certificate to SERVER_ROOT_CA; the firmware verifies HTTPS certificates. Avoid exposing a development computer by forwarding its local port through a home router.

The Arduino sketch contains more than five user-defined functions and a custom Config.h, as required by the project topic sheet. For a real building, install and maintain certified, code-compliant fire alarm equipment.
